# 🚀 Pay2Back | Next-Gen Payment & Margin Ecosystem (Concept Redesign)

[![Netlify Status](https://api.netlify.com/api/v1/badges/default/status?theme=light)](https://pay2back-homepage-v1-0.netlify.app/)

A high-performance, responsive fintech landing page built for **Pay2Back**. Designed with a modern SaaS aesthetic, fluid micro-interactions, and a custom hardware-accelerated performance engine.

**🌍 Live Preview:** [View the Live Deployment Here](https://pay2back-homepage-v1-0.netlify.app/)

## ✨ Key Architectural Features

* **🎨 Dynamic Mesh Gradient System:** Dual-mode (Light/OLED Dark) background mesh built with multi-layered radial gradients and smooth keyframe shifts.
* **⚡ High-Performance GPU Scroll Reveal:** Custom vanilla JavaScript `IntersectionObserver` combined with `translate3d` GPU acceleration to maintain a locked 60fps scroll experience without layout shifts.
* **📱 Responsive Mobile Experience:** Features a custom touch-enabled mobile carousel with auto-scroll capabilities and a native sticky bottom CTA conversion bar.
* **⚙️ Interactive Core Architecture:** Features a custom, zero-dependency SVG interactive routing matrix explaining instant merchant settlements and real-time margins.
* **🌙 Persistent Dark Mode:** Seamless state toggling with Alpine.js across all glassmorphic cards, panels, and borders.

## 🛠️ Tech Stack

* **Markup & Structure:** HTML5 (Semantic, SEO-Optimized)
* **Styling Framework:** Tailwind CSS (via CDN with customized JIT theme extensions & bespoke CSS animations)
* **Interactivity & State:** Alpine.js (Lightweight reactive components)
* **Typography:** Plus Jakarta Sans (Google Fonts)
* **Deployment:** Netlify (Global edge CDN)

## 🚀 Running Locally

To run this project locally on your machine:

1. Clone the repository:
   `git clone https://github.com/sarajittbiswas/pay2back-homepage.git`

2. Open the directory:
   `cd pay2back-homepage`

3. Open `index.html` in your browser, or use an extension like VS Code Live Server for hot reloading.
